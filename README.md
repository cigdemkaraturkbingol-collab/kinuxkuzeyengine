# KuzeyEngine

Chromium, Android WebView veya GeckoView kullanmadan yazılan deneysel Android tarayıcı motoru.

## v0.1
- Kotlin Android uygulaması
- `HttpURLConnection` tabanlı KuzeyNetwork
- Basit HTML tokenizer/parser
- Android Canvas üzerinde özel metin renderer
- Geri / ileri / yenile / adres çubuğu
- GitHub Actions ile debug APK

> Bu erken bir prototiptir. CSS, JavaScript, resimler, formlar ve tam web uyumluluğu henüz yoktur.
